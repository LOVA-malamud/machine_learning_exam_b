## How to study

Open any linked text file directly on GitHub; no installation is required. Recalculate the worked examples, explain each metric in your own words, then compare the assumptions with the original exam prompt. The original numbering is retained; there is no `02` file in this snapshot.

There is no test suite or dataset in this repository. The documentation pass validates the file links, not every mathematical answer. For executable regression exercises, see [LOVA_M](https://github.com/LOVA-malamud/LOVA_M).
